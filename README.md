# insights.medialyzer.com

Medialyzer's public reports, served as plain files at https://insights.medialyzer.com (GitHub Pages).

- A report goes in as `<topic>-<year>-<language>.pdf`, e.g. `tv-attribution-benchmark-2026-tr.pdf`.
- Everything in this repository is public. Put only reports that are already meant for the public here.
- The root address forwards to www.medialyzer.com.
- DNS: `insights` CNAME `medialyzer.github.io` (GoDaddy).
